# Virtual Whiteboard

A gesture-controlled drawing application built using Python, OpenCV, and MediaPipe.

# Features

- Real-time hand tracking
- Finger detection
- Gesture-based drawing
- Smooth drawing experience

# Technologies Used

- Python
- OpenCV
- MediaPipe

# Installation

Clone the repository:

```bash
git clone https://github.com/user-rxhxn/virtual-whiteboard.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python whiteboard2.py
```
